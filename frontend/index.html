SawitDB is a sovereign agrarian database solution stored in native .sawit binary files.

The system features a custom Paged Heap File architecture similar to SQLite, using fixed-size 4KB pages to ensure minimal memory usage and predictable zero-allocation lookups. What differentiates SawitDB is its native Agricultural Query Language (AQL), which replaces standard SQL keywords with intuitive Indonesian farming terminology.

cell_tower Now with Network Edition! Connect via TCP using sawitdb:// protocol similar to MongoDB and Redis.

Engine Specifications

Under the Hood: WowoEngine v1.0

Zero-bloat storage primitives calibrated for dense agricultural yield matrices, telemetric drone telemetry, and high-frequency crop logs.

SPEC-EXT: .SAWIT folder_data

Binary Block Format

Proprietary single-file container storing schema headers, heap catalogs, and encrypted telemetry records within an atomized binary chunk stream.

Header Magic Byte: 0x53 0x41 0x57 (SAW)
Endianness: Little Endian / IEEE 754
Checksum: CRC32-Poly-Harvest
STORAGE: HEAP memory

4KB Paged Heap File

Modeled after SQLite page frames. Each memory cell maps directly to OS page cache boundaries, eliminating virtual translation overhead during disk flushes.

Page Fragmentation 0.04% (Optimized)
DAEMON: TCP/IP hub

Distributed Cluster Daemon

Multiplexed bi-directional framed socket protocol. Supports master-replica plantation clustering with automatic failover across field stations.
